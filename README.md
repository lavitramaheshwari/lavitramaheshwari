### Featured Projects

**♞ [Chess Piece Detection](https://github.com/lavitramaheshwari/Chess-Piece)**
A browser-based chessboard recognition system that detects the board and individual pieces from a camera or image, then converts the position into **FEN notation**. The custom YOLO model runs client-side using **ONNX Runtime Web**, so images do not need to be uploaded to a server.

**♟ [Sudoku Solver](https://github.com/lavitramaheshwari/Sudoku)**
An end-to-end computer vision pipeline that takes a photo of a Sudoku puzzle, detects and warps the grid, recognizes digits with a CNN, solves the puzzle using backtracking, and draws the solution back onto the original image.

**🎤 [TEDxGIIS Youth Website](https://github.com/Vasipallie/TEDxGIIS26)**
A full-stack website built for the TEDxGIIS Youth event using **Node.js, Express, Supabase, and EJS**.

**🎵 [Music Management System](https://github.com/lavitramaheshwari/Music-Management)**
A Python and SQL project for organizing and managing music catalog data such as artists, albums, tracks, and genres.
